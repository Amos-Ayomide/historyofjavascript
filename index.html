HISTORY OF JAVASCRIPT

The History of JavaScript: ES1 to ES6

1995 - The Birth

  • Created by Brendan Eich at Netscape in just 10 days
  • Originally called Mocha, then LiveScript, finally JavaScript

ES1 - ECMAScript 1 (June 1997)

  • First standardized version
  • Established core syntax: types, statements, functions, objects
  • Goal: unify JavaScript across browsers

ES2 - ECMAScript 2 (June 1998)

  • Minor editorial update to align with ISO standard
  • No major new features

ES3 - ECMAScript 3 (Dec 1999)

  • The version that made JS popular. Base for browsers for 10 years
  • Added: do-while, switch, try/catch, ===, in, instanceof
  • Regular expressions, better string handling, better error handling

ES4 - The Version That Never Shipped

  • Too ambitious, huge disagreements
  • Proposed classes, modules, types. Project abandoned
  • Led to split that created ActionScript 3

ES5 - ECMAScript 5 (Dec 2009)

  • The big comeback after 10 years of silence
  • Strict mode: "use strict"
  • Added: JSON support, Array.forEach, map, filter, reduce, isArray
  • Object.create, defineProperty, getters/setters, bind()

ES5.1 - (June 2011)

  • Small alignment with ISO. No dev-facing features

ES6 / ES2015 - ECMAScript 6 (June 2015)

  • Biggest update in JS history. Modern JavaScript starts here
  • Variables: let, const, block scope
  • Functions: Arrow functions =>, default parameters, rest/spread ...
  • Objects/Classes: class, extends, template literals `` `, destructuring, enhanced object literals
  • Modules: import / export
  • New Data Structures: Promise, Map, Set, Symbol
  • Iterators: for...of, generators
